# 04 写字时手掌误触（笔的防误触）

## 现象

用笔写字时手掌压到屏幕上会画线/乱点。

## 修复

iptsd 自带「笔在场就忽略手指」的开关，加一行即可：

```ini
# /data/vendor/iptsd.d/90-touch.conf
[Touchscreen]
DisableOnStylus = true
```

含义：笔在屏幕附近（悬停或书写）时，**整块触摸屏的手指输入被忽略**；
笔离开约 1 秒后手指恢复。

重启 iptsd 生效（不用重启系统）：

```sh
su -c 'killall -9 iptsd; sh /data/local/tmp/start-iptsd.sh'
```

## 备选

如果发现「笔拿开后手指要等很久才恢复」，改用只针对手掌的方案：

```ini
[Touchscreen]
DisableOnPalm = true
```

它只在识别到「大接触面（手掌）」时禁用触摸，不依赖笔的在场状态，副作用更小，
但防误触没有 `DisableOnStylus` 彻底。

## 注意

- 这两项都**只影响手指**，笔的压感、倾斜、橡皮照常。
- 改参数会导致 iptsd 重启，笔会瞬断 1~2 秒，属正常。
