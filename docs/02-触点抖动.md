# 02 触点抖动：手势时好时坏

## 现象

滑动小白条、侧边返回这类手势「滑一会儿行、一会儿不行」；点击偶尔没反应。

## 诊断

用 `getevent` 抓 `IPTSD Virtual Touchscreen`，发现手指明明没抬，事件却是一串：

```
BTN_TOUCH DOWN  552.367
BTN_TOUCH UP    552.447   ← 80ms 后就 UP
BTN_TOUCH DOWN  552.457   ← 10ms 后又 DOWN
```

统计 60 次按下，其中 **39 次短于 150ms**，中位数 120ms。
Android 看到的是一串「快速点击」，所以连续手势被判成点击或直接取消。

## 根因

iptsd 的**稳定性判定**对 THC 热图太严格：触点尺寸/位置/方向一旦变化超过默认阈值，
就判定这一帧不可信、直接丢弃，下一帧重新识别 → 表现就是不断 UP/DOWN。

## 修复

放宽这三个阈值（详见 `config/90-touch.conf`）：

```ini
[Contacts]
SizeThresholdMin = 0.01
SizeThresholdMax = 10.0
PositionThresholdMin = 0.001
PositionThresholdMax = 20.0
OrientationThresholdMin = 0.1
OrientationThresholdMax = 180
```

改完重启 iptsd：

```sh
su -c 'killall -9 iptsd; sh /data/local/tmp/start-iptsd.sh'
```

## 验证

同样 30 秒内的抓包：快速重触从「成片出现」降到偶发（32 秒里只剩 4 次），
其余都是正常间隔的独立点击，连续滑动成立。

日志里应该出现 `Loading config /data/vendor/iptsd.d/90-touch.conf.`。

## 注意

只想解决抖动时，**不要**顺手把 `ActivationThreshold` 调高（如 24/20），
那会让轻触直接识别不到，手感变成「滑都滑不了」。
